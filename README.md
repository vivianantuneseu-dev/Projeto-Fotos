# Projeto Fotos
--Leitor de Notas Fiscais e Boletos

Aplicação desenvolvida em JavaScript para automatizar a leitura de documentos financeiros (notas fiscais e boletos) e auxiliar no controle, soma e equilíbrio de gastos.

---

## 📌 Sobre o Projeto

O objetivo deste projeto é otimizar o gerenciamento financeiro, reduzindo a digitação manual de dados. O sistema realiza a leitura de dados essenciais em notas e boletos, calcula a soma das despesas e organiza os valores para controle orçamentário.

---

## 🎯 Funcionalidades

* 📑 **Leitura Automática:** Extração de valores e dados de boletos e notas fiscais.
* 📊 **Gestão de Gastos:** Soma automatizada e organização das despesas.
* ⚖️ **Equilíbrio Financeiro:** Visão clara do acumulado de gastos.
